# Ta3m Bledi

## Présentation

Ta3m Bledi est une plateforme dédiée à la préservation et à la valorisation des variétés agricoles tunisiennes.

## Objectif

Notre projet vise à sensibiliser à la préservation du patrimoine agricole tunisien et à faciliter la découverte et le suivi des variétés locales.

## Fonctionnalités

- Consulter les variétés agricoles tunisiennes
- Consulter les informations sur les graines
- Gérer ses plantations
- Suivre ses plantations
- Consulter l'historique
- Obtenir des recommandations

## Technologies utilisées

- Java
- HTML
- CSS
- PHP 

## Équipe

Projet réalisé dans le cadre du projet universitaire.
